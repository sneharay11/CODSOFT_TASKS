# CareerHub – Job Portal

CareerHub is a full-stack job portal developed as part of my CodeSoft internship tasks.

## Features
- Candidate registration and login
- Browse job listings and view job details
- Apply for jobs
- Track applications and application statuses
- Recruiter dashboard with applicant details
- Post new job listings
- Update applicant statuses

## Technologies Used
- Next.js and React
- TypeScript
- Tailwind CSS
- Prisma ORM
- PostgreSQL
- Auth.js

## Getting Started

1. Clone the repository.
2. Open the `CareerHub` folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a local `.env` file with your database connection and authentication secrets.
5. Configure the database and run the required Prisma migrations.
6. Start the development server:

   ```bash
   npm run dev
   ```

7. Open `http://localhost:3000` in your browser.

## Security
Never commit `.env` files, authentication secrets, or database credentials to GitHub.
